시트 연동 설정

아래 Apps Script 주소를 넣는 것이 기본 방식입니다. 주소가 있으면 데이터를 스크립트로 읽고 쓰기 때문에, 시트를 비공개로 둬도 되고 브라우저 차단(Failed to fetch)도 생기지 않습니다.

Apps Script 주소가 없을 때만 시트 CSV를 직접 읽습니다. 이 방식은 실제 웹사이트에서는 구글이 막는 경우가 많습니다.

Apps Script 연결

doGet은 목록을 읽고, doPost는 중지/재개를 기록합니다. 둘 다 있어야 합니다.

  1. 시트에서 확장 프로그램 → Apps Script 열기
  2. 아래 코드를 전체 교체로 붙여넣고 저장
  3. 배포 → 새 배포 → 웹 앱, 실행 주체 나, 액세스 권한 모든 사용자
  4. 발급된 /exec 주소를 아래에 붙여넣기

이미 배포한 뒤 코드를 고쳤다면 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 해야 반영됩니다. 저장만으로는 바뀌지 않습니다.
